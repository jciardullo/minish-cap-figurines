PAL / European: memorize-it knee option

Read chance at the default one-shell wager, before increasing it. Collect completionist resources normally; use ordinary town visits. Full eligibility means the ending plus remaining optional unlock side content; while major side content remains, use the story rows.

During normal progression, use ordinary town visits. Start a session only when the chance is at least 50%. Once started, continue even after it falls below 50%: wager 1 shell if the default one-shell displayed chance is greater than 50%; otherwise raise the display to 100%. If you cannot afford 100%, wager all held shells. Stop when empty; do not farm or buy during these early sessions.

Once every figurine is eligible, wager 1 shell if the default one-shell displayed chance is greater than 7%; otherwise raise the display to 100%. If short of that wager, use all held shells. When empty, aim for a full 90-shell restock: if you have less than 900 R, farm until you reach 900 R, then buy three bundles. This rule tops up to the full batch even if you could already afford one or two bundles. If already funded for all three, go directly to the shop.

Near 999, use an ordinary visit only if the entry test holds; otherwise continue progression. Some overflow is accepted.

Worst-tested regret: 22.78%. The compact table is the default recommendation if a reference is acceptable.

NTSC-U: memorize-it knee option

Read chance at the default one-shell wager, before increasing it. Collect completionist resources normally; use ordinary town visits. Full eligibility means the ending plus remaining optional unlock side content; while major side content remains, use the story rows.

During normal progression, use ordinary town visits. Start a session only when the chance is at least 60%. Once started, continue even after it falls below 60%, always raising the display to 100%. Stop when that wager is unaffordable; do not farm or buy during these early sessions.

Once every figurine is eligible, wager 1 shell if the default one-shell displayed chance is greater than 10%; otherwise raise the display to 100%. Restock before the next pull if its wager is unaffordable. If you can already buy at least one bundle, buy as many as your current rupees afford, up to four bundles. Otherwise farm only the missing money needed for 800 R, then buy four bundles (120 shells).

Near 999, use an ordinary visit only if the entry test holds; otherwise continue progression. Some overflow is accepted.

Worst-tested regret: 21.10%. The compact table is the default recommendation if a reference is acceptable.
